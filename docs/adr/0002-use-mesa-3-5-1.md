# ADR 0002: Use Mesa 3.5.1

## Status

Accepted — 2026-08-28

## Context

The model needs discrete cell space, agent lifecycle management, explicit staged activation, seeded
generators, property layers, data collection, and an interactive debugging view.

## Decision

Pin `mesa[rec]==3.5.1`. Use `mesa.discrete_space`, `AgentSet`, `DataCollector`, model-owned RNGs, and
SolaraViz only within the runtime adapter. Use stable-version documentation.

## Alternatives considered

- **Mesa 4 alpha:** rejected because it is a prerelease with breaking API removals.
- **Custom engine:** rejected because it duplicates tested runtime infrastructure without scientific
  benefit at the current scale.

## Consequences

The project receives a maintained ABM runtime, while adapter isolation contains migration risk.
Deprecation warnings are treated as errors in runtime tests. SolaraViz is debugging infrastructure,
not part of the scientific contract.
