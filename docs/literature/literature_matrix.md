# Literature Matrix

This matrix separates mechanism evidence, interpretation, boundaries, counterevidence, and analysis
methods. A reviewed source licenses only the relation stated in its row. It never authorizes code or
calibrates a numeric parameter unless the notes explicitly identify a calibration design.

Valid `evidence_role` values are `mechanism_foundation`, `mechanism_support`, `interpretation`,
`boundary`, `counterevidence`, `analysis_method`, and `background`.

## Review rule

Rows marked `reading` are not frozen evidence. Before their mechanism or interpretation enters a study
freeze, a paired note must record support, counterevidence/boundaries, observable implications, required
model relations, and every remaining project choice.
