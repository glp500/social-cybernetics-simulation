## Standing boundaries

- Source concentration is not monopoly without exclusive control and feasible alternatives.
- Counterfactual information loss is dependency; it becomes power only if discretionary asymmetric
  control over access is represented and demonstrated.
- D0/D1 transfers are not automatically gifts; flow balance is not sufficient for reciprocity.
- Information credits are conserved experiment tokens, not money.
- Immediate accounted access is not a market: there is no price formation, bargaining, production, or
  generalized exchange.
- Deferred claims are minimal obligations, not anthropological debt generally.
- Capability diffusion is not cumulative culture or institution formation.
- Faster network recovery can coexist with worse material security and must not be called overall
  resilience.

## Required theoretical comparison

Each result considers network economics, social learning/cultural evolution, embeddedness, and
economic-anthropological circulation. Political-economic interpretations must state whether
accumulation, dependency, conditionality, and control are actually represented and which stronger
categories remain prohibited.
