# Interpretation Protocol

## Purpose

This protocol prevents a simulated pattern from being explained only through the theory that
motivated its mechanism. It is mandatory for every headline figure, table, and main result before a
study reaches interpretation freeze.

## Required five-level review

Every result answers:

1. **Mechanical:** which local rule, state, and transition produced the pattern?
2. **Computational:** under which parameters, seeds, horizons, and controls does it reproduce?
3. **Economic:** which distributional, incentive, provisioning, or dependency concepts illuminate it?
4. **Anthropological:** which livelihood, risk, skill, embeddedness, circulation, or obligation
   concepts illuminate it?
5. **Boundary:** which theoretically important social processes are absent?

## Mandatory result table

Each headline result receives one table with exactly these fields:

| Field | Required content |
| --- | --- |
| observed pattern | named measures, contrast, uncertainty, horizon, and artifact identity |
| mechanical causal explanation | stage-level path from configured difference to recorded outcome |
| economic interpretation | one or more licensed economic readings and their assumptions |
| Marxian / political-economic interpretation | applicable narrow category or an explicit statement that defining relations are absent |
| anthropological interpretation | applicable livelihood, risk, skill, embeddedness, or circulation reading and its assumptions |
| alternative theoretical interpretation | a plausible competing explanation or framing |
| missing mechanisms | material, relational, institutional, historical, or demographic absences |
| prohibited conclusion | the strongest tempting claim that the evidence does not support |

The external refactor listed seven labels but gave eight content fields; all eight are retained because
the Marxian/political-economic entry is analytically distinct from broader economics.

## Writing rules

- Name the model quantity: “cumulative harvest inequality,” not simply “inequality.”
- Name the comparison: condition, seed pairing, duration, and unchanged controls.
- Separate an observed association from its stage-level causal explanation.
- State when a metric is undefined or structurally uninformative for a cohort size.
- Present raw continuous outcomes with any group, cluster, or regime label.
- Report tradeoffs as vectors; never call a condition “better” from one measure.
- Label every numeric setting as calibrated, literature-bounded, or project-chosen.
- Treat alternative interpretations and null/negative findings as evidence, not footnotes.

## Interpretation freeze checklist

A study cannot be marked complete until:

- every main result has an explicit mechanical explanation;
- every theoretical interpretation lists the assumptions it requires;
- economic and anthropological readings are considered where relevant;
- Marxian categories are used only when corresponding relations exist;
- at least one alternative interpretation is recorded;
- absent mechanisms and prohibited conclusions are explicit;
- statements can be reconstructed from immutable published artifacts;
- the interpretation document is versioned with the frozen analysis.
