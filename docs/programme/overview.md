# Social Cybernetics Programme Overview

## Identity

Social Cybernetics is a computational comparative political economy and anthropology of ecological
and informational adaptation. It uses three deliberately constrained agent-based studies to ask how
material environments distribute opportunity, how bounded information changes agents' ability to act
on that opportunity, and how communication networks change the social distribution of information,
advantage, dependency, and resilience.

The simulations establish generative possibility under explicit assumptions. Economic,
political-economic, and anthropological theories provide competing interpretations; they do not add
unmodelled causes or calibrate unrelated parameters.

## Three-study design

| Study | Transformation | Executable status |
| --- | --- | --- |
| Project 1 | environment → objective ecological opportunity and material outcomes | complete; 7/7 gates frozen |
| Project 2 | objective opportunity → perceived and privately actionable opportunity | specified; not implemented |
| Project 3 | private opportunity → socially accessible opportunity | specified; not implemented |

The central synthesis compares three distributions rather than building one mega-simulation:

1. objective resource opportunity from Project 1;
2. privately actionable opportunity after sensing and adaptation in Project 2;
3. socially accessible opportunity after reports and network mediation in Project 3.

At each transformation the programme asks whether inequality grows, shrinks, persists, or changes
form.

## Shared scientific method

Every study follows the same authority chain:

```text
programme scope
  -> study specification
    -> mechanism specification
      -> experiment design
        -> analysis plan
          -> interpretation protocol
            -> code and tests
```

Equations and stage semantics are authoritative for implementation. Immutable records are
authoritative for analysis. Interpretation is explicitly downstream of both.

Every major result is evaluated at five levels:

1. mechanical: which transition produced it;
2. computational: where it reproduces across parameter and seed regimes;
3. economic: which distributional or incentive concepts illuminate it;
4. anthropological: which livelihood, risk, skill, embeddedness, or circulation concepts illuminate
   it;
5. boundary: which missing social processes prohibit broader claims.

## Completion gates

A study is complete only when all seven gates are frozen:

| Gate | Required evidence |
| --- | --- |
| specification | authoritative mechanisms, ordering, units, inputs, and outputs |
| literature | paired supporting evidence, counterevidence, boundaries, and project choices |
| verification | mechanism tests, invariants, fixed trajectories, and architecture checks |
| sensitivity | parameter influence and stochastic variation retained as raw outcomes |
| experiment | preregistered comparisons executed with immutable provenance |
| analysis | definitions and code frozen before headline inference |
| interpretation | causal explanation, alternatives, absences, and prohibited claims recorded |

## Current position

The former v0.1/v0.2 implementation became Project 1's verified mechanical kernel. Project 1 is
complete under the seven-gate definition: its analytical records, derived metrics, 140-run P1-A–E
experiment, 600-run sensitivity screen, and bounded interpretation are frozen against validated local
evidence. Project 2 and Project 3 have complete specification packages but must remain non-executable
until their own gates authorize implementation.
