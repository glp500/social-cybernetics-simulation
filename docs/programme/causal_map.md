# Programme Causal Map

## Common causal spine

```text
Environment
  -> Observation
    -> Belief
      -> Action intent
        -> Gate
          -> Physical resolution
            -> Physiological/material feedback
              -> Measurement
```

Project 1 uses exact local observation, copied belief, a fixed literal policy, and an allow-all gate.
Those identity-like stages remain explicit controls rather than being optimized away. Projects 2 and 3
change only named transformations and preserve the rest as controls.

## Project 1: objective opportunity

```text
baseline landscape + recovery state
  -> regeneration and shock
  -> local resource exposure
  -> fixed harvest-or-move intent
  -> simultaneous allocation
  -> energy, shortfall, movement, mortality
  -> ecological and distributional histories
```

Primary identification question: which unequal outcomes and persistent ranks can arise from ecological
opportunity, mobility, competition, disturbance, and recovery alone?

## Project 2: private information transformation

```text
objective opportunity
  -> C(radius, noise, delay)
  -> timestamped private observation history
  -> simple belief
  -> fixed information-sensitive policy or private Q-learning
  -> decision quality
  -> material conversion of information/adaptive advantage
```

Primary identification question: how much additional inequality is introduced, removed, or transformed
when ecological opportunity is filtered through heterogeneous sensing and private adaptation?

Perception RNG is independent from ecology and policy/learning RNG. Profile assignment in mixed
populations is randomized under a separate recorded stream and cannot be correlated with initial
material position.

## Project 3: social-access transformation

```text
private observation/belief
  + timestamped reports over realized ties
  + directional trust and optional rewiring
  -> fused social belief
  -> socially accessible opportunity
  -> material outcomes and network feedback
```

Capability diffusion changes a complete sensing profile only through the specified simple or
reinforced exposure rule. Circulation D0–D3 changes sender cost, access accounting, or settlement while
holding report content and the comparison's other mechanisms fixed.

## Cross-study decomposition

For matched ecological regimes and seeds, analysis compares:

```text
A: objective material opportunity
  -> B: privately actionable opportunity
    -> C: socially accessible opportunity
```

The synthesis estimates where distributional change enters. It does not assume that later layers
improve welfare or that one statistic summarizes the transformation.

## Prohibited causal shortcuts

- correlations between landscape and outcome do not establish a social relation;
- information-profile/outcome correlation does not establish capital accumulation;
- centrality/outcome correlation does not establish power;
- an obligation ledger does not create physical or informational stock;
- clustered macro-patterns do not establish an institution;
- theoretical interpretation never feeds back into the executable transition unless separately
  specified, validated, and authorized.
